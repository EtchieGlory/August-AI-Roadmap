# 🖼️ Image Toolkit

A simple Python command-line image processing application built with **Pillow (PIL)**.

This project allows users to perform common image operations such as resizing, converting formats, rotating, flipping, and converting images to grayscale.

Built as part of my August AI Roadmap to strengthen Python automation skills and learn how to build practical tools.

---

## 🚀 Features

✅ Resize images  
✅ Convert image formats
✅ Flip images
✅ Rotate images
✅ Convert image to grayscale
 

Supported formats:
- PNG
- JPG/JPEG


✅ Rotate images  
✅ Flip images horizontally or vertically  
✅ Convert images to grayscale  
✅ Batch image conversion support  

---

## 🛠️ Technologies Used

- Python 3
- Pillow (PIL)
